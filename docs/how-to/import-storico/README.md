# Importare lo storico in Health Connect

Scegli l’app in cui si trovano i tuoi dati. Ogni guida distingue sincronizzazione dei nuovi dati, recupero del passato e importazione dei file.

| App di origine | Guida | Metodo descritto |
| --- | --- | --- |
| Samsung Health | [Guida Samsung Health](samsung-health.md) | Collegamento diretto; recupero con Health Sync se necessario. |
| Zepp / Amazfit | [Guida Zepp](zepp.md) | Collegamento diretto; file compatibili o screenshot per dati mancanti. |
| Garmin Connect | [Guida Garmin](garmin-connect.md) | Collegamento diretto, storico tramite intermediario, file FIT. |
| Fitbit / Google Health | [Guida Fitbit](fitbit.md) | Collegamento diretto; verifica del passato ed esportazione. |
| Huawei Health | [Guida Huawei](huawei-health.md) | Trasferimento tramite Health Sync e Health Kit, dove disponibili. |
| Apple Salute | [Guida Apple Salute](apple-health.md) | Esportazione ZIP da iPhone e importazione con OpenVitals su Android. |

Prima di iniziare leggi [permessi, controllo dei risultati e prevenzione dei duplicati](preparazione.md). Le istruzioni sono state verificate sulla documentazione disponibile l’11 novembre 2026; menu, categorie e limiti possono cambiare.

## Quale metodo scegliere?

- Se ti interessano i dati nuovi, prova il collegamento diretto a Health Connect.
- Per i dati precedenti, verifica prima una data passata: la presenza nell’app originale non prova il trasferimento.
- Per file già esportati, usa l’importatore corrispondente. OpenVitals supporta [Apple Health](../../features/apple-health-import.md), [FIT](../../features/fit-files-import.md) e [CSV con mappatura delle colonne](../../features/csv-import.md). Un archivio generico del produttore non è automaticamente compatibile.
- Per singoli dati visibili puoi usare gli screenshot; controlla sempre data, ora, unità e anteprima prima del salvataggio.
